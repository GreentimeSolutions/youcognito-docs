# Youcognito Run game

**Youcognito Run** is a quick browser game starring the fedora spy ghost under a crescent moon: float through the night, dodge the trackers, and chase a high score.

![Play Youcognito Run card](../.gitbook/assets/youcognito-run-card.png)

* Play it: [remix.gg/g/youcognito-run](https://remix.gg/g/youcognito-run)
* In the app: the **Play Youcognito Run** card on the home screen and the **Run** quick tile.
* It runs on Remix, so it opens in a new tab, or in Farcaster's browser when you're in the Mini App.

The game is a separate fun extra. It doesn't affect your faucet claims or streaks.
